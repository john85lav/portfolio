# RootDeck — SSH-клиент с ИИ-агентами на сервере

> Страница для технического интервью. Короткая версия — в [README](../README.md).

Управление серверами с iPhone, iPad, Mac и Android.
[Опубликован в App Store](https://apps.apple.com/app/id6794034566) (Mac App Store —
15 августа 2026, бесплатно, 174 страны). Приложение не собирает данные:
секреты — в Keychain, профили — на устройстве.

SwiftUI · SwiftNIO SSH (свой форк Citadel) · Swift Concurrency · Live Activities ·
Kotlin + Jetpack Compose (порт на Android). ~68 тыс. строк Swift, 938 тестов,
порт на Android ~30 тыс. строк Kotlin. Репозиторий создан 11 июля 2026, первая
публикация — через 5 недель.

## Возможности

- **Терминал:** PTY, ANSI-цвета, полноэкранные программы (`htop`, `vim`),
  подсказки команд серым продолжением строки. На Mac — до 8 вкладок по 4 панели.
- **Файлы по SFTP:** браузер в стиле Finder, очередь загрузок с отменой и
  повтором, встроенный редактор, инспектор прав и симлинков.
- **Мониторинг сервера:** CPU, память, GPU, сеть, диски, процессы в реальном
  времени; живой просмотр логов.
- **Безопасность:** вход по паролю или ключу (ed25519 / RSA с passphrase),
  проверка ключа хоста по отпечатку SHA-256 с предупреждением при смене,
  блокировка приложения Face ID / Touch ID, jump host.
- **Поиск SSH-серверов в сети:** Bonjour + опрос порта 22 по подсети.
- **Вкладка «Агент»:** чат с Codex, Claude Code и другими агентами, которые
  работают на сервере пользователя → [разбор 07](../cases/07-rootdeck-remote-agent.md).

## Ключевые технические решения

**Пул SSH-соединений для терминалов.** Сервер держит около 5 PTY на одно
соединение; дальше открытие терминала молча зависает. Вместо искусственного
лимита в интерфейсе сделан пул: каждая следующая группа панелей получает
отдельное соединение с теми же учётными данными и своим самовосстановлением.

**Утечка каналов в библиотеке SSH.** Отменённые по тайм-ауту команды не закрывали
канал на стороне клиента; они копились до лимита `MaxSessions` сервера, после
чего падал keepalive и соединение уходило в бесконечное переподключение.
Для долгих команд используется API, который закрывает канал сам; попутно
исправлен сбой SwiftNIO SSH при закрытии занятого канала (патч во встроенной копии библиотеки).

**Фоновая работа на iOS** — замерена `tcpdump` на сервере, а не по логам
телефона → [разбор 06](../cases/06-rootdeck-ios-background-ssh.md).

**Диагностика «дошла ли операция до сервера».** SSH зашифрован, по сетевому
дампу видны только размеры. Включение подробного журнала `sftp-server` на
тестовом сервере показало, что клиент отправил `opendir` и больше ничего — так
нашёлся баг, из-за которого приложение само убивало живое соединение ровно через
31 секунду.

**Прокрутка чата как в Claude для iOS** (своя реплика уезжает наверх и остаётся,
ответ растёт под ней). Готовые подходы на iOS 26 давали дёрганье; решение найдено
на отдельном стенде-прототипе, где каждая находка устраняла свой класс ошибок, и
только потом перенесено в экран.

## Процесс

- `CHANGELOG.md` ведётся сразу после изменения, с готовыми текстами «Что нового»
  на русском и английском для App Store Connect.
- Каждая функция сначала обсуждается по экранам, потом пишется; для порта на
  Android по ходу пишется спецификация (например, поиска серверов).
- Публикация: App Privacy, политика конфиденциальности, DSA-декларация ЕС, выбор
  стран — всё пройдено самостоятельно.
